HOW TO APPLY - the easy way
1. Download LocalLinkBackend_fixup_v2.zip from the chat.

2. Extract it OUTSIDE the repository. Not into it:

     Expand-Archive -Path "$env:USERPROFILE\Downloads\LocalLinkBackend_fixup_v2.zip" -DestinationPath "$env:USERPROFILE\Downloads\fixup2" -Force

   Extracting an archive into the repo folder is what caused all of this. Keep
   archives outside it.

3. Run the script. It checks each step and stops with a message if something
   looks wrong instead of carrying on:

     powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\fixup2\FIX_REPO.ps1"

4. If it ends with "Done", publish it (the script deliberately does not push):

     cd "$env:USERPROFILE\Downloads\localLinkBackend"
     git push origin main

WHAT THE SCRIPT DOES
  - clears stray LOCALLINK_* variables in that window (see the test note below)
  - saves any uncommitted changes to a git stash, so nothing is lost
  - pulls main
  - applies the three commits from the bundle
  - moves leftovers (changed-files, README, bundles, patches) out of the repo
    into ..\_cleaned_from_repo_<timestamp>\ - it does not delete them
  - runs go build ./... and go test ./...
  - prints the push command and how to start the server

MANUAL EQUIVALENT, if you would rather type it yourself
  cd "$env:USERPROFILE\Downloads\localLinkBackend"
  git pull --ff-only origin main
  git fetch ..\fixup2\locallink_backend_fixup2.bundle fixall:fixall
  git merge --ff-only fixall
  Remove-Item -Recurse -Force .\changed-files
  go build ./...
  go test ./...
  git push origin main

  Or, without a bundle:
  git am --3way "$env:USERPROFILE\Downloads\fixup2\locallink_backend_fixup2.patch"

WHY go test FAILED EARLIER
  TestValidateProductionSecretsRequiresPairingCode failed with
  "LOCALLINK_REQUIRE_TLS must remain true in production". That is not a code
  fault: you had set $env:LOCALLINK_REQUIRE_TLS="false" in the same PowerShell
  window to run the server, and the test asserts that a production
  configuration without TLS is rejected. Clear it, or use a fresh window:

    Remove-Item Env:LOCALLINK_REQUIRE_TLS

  The script clears those variables for its own run.

AFTERWARDS - optional, three lines

    git commit -m "Stop tracking the runtime database"
